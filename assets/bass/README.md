# Linia de bas din Etapa „Muzician”

`selekt-bass.mid`, linia de bas din exemplele lecției „Tu și basistul”
(`src/drums/theory/lessons/musician.ts`, constanta `SELEKT_BASS`).

- Descărcat de pe Selekt (https://selektaudio.com), MIDI transcris din audio.
- Sursa originală: „Give it LOOP BASS & DRUMS 90 BPM” de johntrap,
  Freesound 614195, https://freesound.org/people/johntrap/sounds/614195/
- Licența: CC0 1.0 (domeniu public), fără atribuire obligatorie.
- Certificatul Selekt: `selekt-bass-certificate.pdf`.

Aplicația nu citește fișierul la rulare: notele sunt copiate, cuantizate pe
șaisprezecimi, în `musician.ts`. Fișierul stă aici ca sursă și ca dovadă de
proveniență.
